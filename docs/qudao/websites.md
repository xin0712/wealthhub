下列为与投资研究相关的高质量网站清单（持续补充）：

| 网站名称 | 网站链接 | 用途 |
| :-- | :-- | :-- |
| NASDAQ | https://www.nasdaq.com | 官方信息门户：查询 NASDAQ-100 指数成分与权重、指数方法论文档、上市公司公告与行情、历史数据与市场新闻聚合，适合进行指数/成分股的权威核验与资料下载。 |
| Yahoo Finance | https://finance.yahoo.com | 全球行情与财务概览：个股/指数/基金报价、财务报表要点、估值指标、历史价格与新闻聚合；适合快速查价、对比估值与导出基础时间序列。 |
| Google Finance | https://www.google.com/finance | 快速行情与新闻聚合：公司概览、实时/延时价格、简要财务与同类对比，支持多标的同图对比，适合快速浏览与入门查询。 |
| Morningstar | https://www.morningstar.com | 基金与 ETF 深度研究：评级、费用、持仓、风格箱、风险收益指标与历史表现，适合做基金/ETF 的体系化比较。 |
| TradingView | https://www.tradingview.com | 高级图表与技术分析：丰富技术指标、多周期联动、脚本策略与回测、社区观点与交易想法分享，适合技术派与图表派。 |
| GuruFocus | https://www.gurufocus.com | 价值投资数据平台：财务质量评分、估值模型（DCF/倍数）、红黄绿风险提示、知名投资人 13F 持仓跟踪，适合基本面筛选与估值复核。 |
| Macrotrends | https://www.macrotrends.net | 长期时间序列与宏观数据：公司与宏观指标的长期历史数据与可视化（利率、通胀、PE、GDP 等），支持下载与对比，适合做趋势研究。 |
