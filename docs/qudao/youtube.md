作者在 YouTube 上关注的与投资、估值、宏观相关的优质频道清单：

| 频道名称 / 主讲人 | 主要方向 | 推荐理由 |
| --- | --- | --- |
| The Plain Bagel | 基本面分析、估值教学 | 用通俗方式讲解 PE、DCF、ROE 等核心概念，非常适合打基础。 |
| Aswath Damodaran（官方频道） | 公司估值、财务模型 | NYU 课堂录播，最系统的估值教学资源。 |
| Ben Felix / Ben Carlson | 资产配置、长期投资 | 从数据与学术角度讲 ETF、股债比例、因子投资，非常理性。 |
| Jeffrey Gundlach / David Rosenberg（Macro Voices 常客） | 债券、利率、通胀周期 | 债券之王 Gundlach 与 Rosenberg 讨论宏观趋势，帮助理解债市与经济周期。 |
| Adrian Day Asset Management | 黄金与大宗商品 | 强调黄金的战略属性与周期定位，对抗通胀或危机视角深刻。 |
| Gold Silver World | 黄金、通胀、美元走势 | 分析黄金基本面、供需、政策与美元指数的关系。 |
| “It’s A Critical Moment for Gold, Stocks, Bonds…”（Macro Analysis 类频道） | 股、债、金三类资产周期联动 | 综合讨论三大资产的周期关系与拐点，适合资产配置学习者。 |
| Real Vision Finance（Raoul Pal 主导） | 宏观经济、加密 & 黄金 | 邀请基金经理、央行前高官，深度探讨全球流动性、通胀与资产价格。 |
| Meet Kevin | 美股、宏观数据解读 | 有一定个人色彩，但能快速跟踪市场新闻与数据，适合日常信息输入。 |
| Ray Dalio 官方频道 | 宏观周期、债务周期 | 桥水基金创始人，用极简动画讲周期理论，宏观框架必看。 |

> 说明：以上为内容参考清单，后续会补充频道链接、分组订阅建议与提醒设置等实用指引。
